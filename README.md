**Chat App**

Клиент-серверный чат на C# и WPF.

**Возможности**

- регистрация новых пользователей;
- авторизация существующих пользователей;
- хранение учетных данных пользователей;
- хеширование паролей с использованием PBKDF2;
- поддержка личных сообщений между пользователями;
- создание групповых чатов;
- приглашение пользователей в комнаты;
- обмен сообщениями в групповых чатах;
- хранение истории сообщений;
- загрузка предыдущей истории переписки;
- пересылка сообщений;
- отображение списка доступных чатов и комнат;
- клиент-серверное взаимодействие по TCP;
- подключение клиента к серверу по IP-адресу и порту;
- поддержка одновременной работы нескольких пользователей;
- обработка сетевых сообщений на сервере;
- разделение клиентской и серверной логики;
- использование общих моделей данных между клиентом и сервером;
- шифрование сообщений с использованием AES;
- хранение данных приложения в JSON-файлах;
- отдельный WPF-интерфейс для клиентской части;
- обработка ошибок подключения;
- проверка доступности сервера;
- возможность локального запуска клиента и сервера на одном компьютере;
- возможность подключения клиента к серверу по локальной сети;
- возможность работы через внешний сервер или TCP-туннель;
- отдельный модуль тестирования криптографической части;
- сохранение пользователей, комнат и истории между запусками сервера.

**Запуск**

1. Запустить сервер.
2. Запустить клиент.
3. Подключиться к серверу по адресу и порту 5000.
